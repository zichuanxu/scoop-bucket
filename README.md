# zichuanxu/scoop-bucket

Scoop manifests for [godl](https://github.com/zichuanxu/godl), a fast, cross-platform download manager.

```powershell
scoop bucket add zichuanxu https://github.com/zichuanxu/scoop-bucket
scoop install godl-desktop   # desktop app (portable)
scoop install godl           # CLI and service
```

godl is unsigned; if SmartScreen warns, choose More info → Run anyway. The manifests are generated by godl's release workflow.
