# zichuanxu/scoop-bucket

Scoop manifests for [NimGet](https://github.com/zichuanxu/nimget), a fast, cross-platform download manager.

```powershell
scoop bucket add zichuanxu https://github.com/zichuanxu/scoop-bucket
scoop install nimget-desktop   # desktop app (portable)
scoop install nimget           # CLI and service
```

NimGet is unsigned; if SmartScreen warns, choose More info → Run anyway. The manifests are generated by NimGet's release workflow.
